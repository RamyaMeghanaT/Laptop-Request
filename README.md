# Laptop-Request
A simple ServiceNow Service Catalog project for creating laptop requests using Catalog Items and Variables.

## Overview

Created a Laptop Request Catalog Item under the Hardware category.
Users can select laptop details and provide the required information through the request form.

### ServiceNow Concepts & Implementation

#### Service Catalog
Used Service Catalog to create the laptop request.

#### Catalog Item
Created a Laptop Request Catalog Item under the Hardware category.

#### Variables
Configured variables to collect:
- User Reference
- Need-by Date
- Laptop Model
- Request Details

#### REQ, RITM & SCTASK
Learned the basic request hierarchy generated from Service Catalog requests.
